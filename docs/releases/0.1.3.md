# sdc 0.1.3

A patch release after 0.1.2, the same day: the documentation site and its generator. No protocol,
binding or case changed, and the driver's behaviour did not change. A source release at tag
`0.1.3`; nothing is published to crates.io and no interface is stable. `CHANGELOG.md` lists the
changes with their commits.

### What changed

- The documentation site, https://beyond10x.github.io/sdc/, built from `website/` and published
  by `.github/workflows/pages.yml` and `.github/workflows/b10x-docs-site.yml` on every push to
  `main`. It covers what the SDC is, the main flow, one page per protocol, what the SDC is built
  on, the evaluation per release and model setting, and one run step by step ("The LLM is not the
  runtime"). The build refuses fixture data.
- `sdc-protocol-site` generates the site's protocol data (`website/data/protocols/`) from the
  protocol YAML, the bindings and the committed check outputs. `scripts/check-bindings.sh` runs
  its `check`, which fails when the data is stale, including after a new release section in
  `CHANGELOG.md`.
- Each run in `docs/progress.json` carries its metrics: cost, wall time, model and decider calls,
  rework takes, review and merge rejections, looping factor and first-pass yield per node, and stop
  cause.
- `task docs`, `docs:generate`, `docs:build` and `docs:test`: the site's data check, build and smoke
  test (every page at 1440 and 390 px in both themes, axe, internal links).
- Two experiment records are registered before their runs, on the 0.1.2 tree: `release-0.1.2`,
  the baseline of 0.1.2 with its predictions against `baseline-0.1.0`, and `effort-decider-mixed`,
  the mixed setting's Haiku decider at effort medium against xhigh. Both are planned; the progress
  ledger lists them with no result.

### Checks on this tree

- `scripts/run-finding-cycles.sh`: 98 expected cycles and 2 pending (`rework-spent-dropped`,
  `rework-spent-abandoned`, routes not built yet, which never fail the script).
- `scripts/evaluate-cases.sh`: 52 situations in 12 fixture cases.
- `scripts/check-bindings.sh`: the bindings, the route findings, the experiment records and the
  site's protocol data current.
- `task docs:build` and `task docs:test`: the site builds without fixture data and its smoke test
  passes.

### Limits

- No run has used the 0.1.2 or the 0.1.3 tree. The baseline is still `experiments/baseline-0.1.0`
  (three runs per setting on the 0.1.0 tree `4468bfd`): 6 of 9 clean passes.
- A check of the delivered product against its specification is in work and not in this release.
- Nobody started the delivered product.
- The driver's runtime parts are a temporary copy of what the Loom runtime must provide.
