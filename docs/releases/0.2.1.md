# Runbook 0.2.1

A patch release of 0.2.0, the same day. It fixes two defects of the 0.2.0 tree that only the
documentation checks see. The driver, the protocols, the bindings, the tools and the run inspector
are those of 0.2.0 except for the version number, so nothing a run does changes. A source release at tag `0.2.1`;
nothing is published to crates.io and no interface is stable. `CHANGELOG.md` lists the changes with
their commits. Read `docs/releases/0.2.0.md` for the release this one repairs.

### What changed

- **The evaluation smoke test.** `website/tests/smoke.spec.ts` expected the evaluation page's
  list of releases without runs to be exactly "0.1.1, 0.1.3, 0.1.4". The 0.2.0 ledger entry has no
  runs yet, so the page listed it too. Four smoke tests failed (1440 and 390 px, both themes), and
  `Documentation validation` failed on the 0.2.0 tag commit, so the site was not published from
  it. The assertion now requires those three releases first and admits any later ones (`e46a237`).
- **The protocol index.** `website/data/protocols/index.json` was stale on the 0.2.0 tree: a
  line added to the 0.2.0 `CHANGELOG.md` section after the site data was written. It is written
  again by `sdc-protocol-site write` (`e46a237`), and once more for this release.

No run metric is affected.
