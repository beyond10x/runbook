# sdc 0.1.2

A patch release after 0.1.1, the same day: corrections to the figures of 0.1.0, recorded replay,
the timeline of a run, one rework cap, the LLM decider's principal renamed, and the root
protocol's description. No rule of a protocol changed. A source release at tag `0.1.2`; nothing is
published to crates.io and no interface is stable. `CHANGELOG.md` lists the changes with their
commits.

### What changed

- Recorded replay: `scripts/run-trial.sh <run> --autopilot --recorded <source>` re-drives a
  recorded run with the real driver and programs and the recorded model replies, through
  `sdc-replay`. `--set` changes a condition (the rework cap, timeouts, retries, run caps),
  `--inject` puts a decision in place of a recorded one, and `--on-divergence stop|nearest|live`
  says what a call the source never made gets. A re-driven run has `run.unstick` off unless the
  source called it (`--set unstick=on` decides otherwise). This is the feature 0.1.1 left out.
- `sdc-run-timeline` writes the timeline of one run (`sdc.run-timeline/1`); the timelines of
  `trial-0.1.0-strong-1` and `trial-0.1.0-mixed-1` are under
  `experiments/baseline-0.1.0/timelines/`.
- One rework cap: `rework_limit` of `rule-ends.json` is the default and `SDC_MAX_REJECTIONS`
  overrides it. `run-settings.jsonl` records the cap a run had as `rework_limit: {value, source}`,
  and the driver and the writer's rework prompt read that one value. Before, the prompt said "of
  at most 2" whatever the driver enforced.
- The LLM decider is the principal `decider:model`, with its model id recorded beside it.
  `SDC_DECIDER=haiku` still works as an alias.
- "SDC" stands for "software delivery cycle": the root protocol's description said "development".
  The description is the only change to `protocol/sdc.protocol.yaml`, so its compiled IR hash
  changed (`41c6acc7…` to `8a05e12f…`) and `canon simulate` gives the pinned report byte for byte.

### Reading runs made before 0.1.2

- `decider:haiku` in a run before 0.1.2 is the same principal as `decider:model`: the LLM decider,
  whatever its model. The strong runs of trial 3 recorded an Opus decider as `decider:haiku`; the
  model id in `run-settings.jsonl` and on each `decisions.jsonl` line says which model decided.
  The tools and the live view read both names, and `sdc-experiment` counts `haiku` and `model` as
  one setting. Recorded runs, trial reports and fixtures keep the old name, as recorded.
- A case started before 0.1.2 records the root protocol's IR hash `41c6acc7…`; one started on 0.1.2
  records `8a05e12f…`. The two IRs differ only in the description.
- Runs before 0.1.2 have no `rework_limit` in `run-settings.jsonl`; their cap was `rework_limit` of
  `rule-ends.json` (2), and their rework prompts said "of at most 2".

### Corrections to 0.1.0

`sdc-run-compare` left out the cost of every decider call whose escalation was suppressed (fixed
in 0.1.1). Of the seven Trial 3 passes in the 0.1.0 notes, only `trial-3-haiku-7` had such a call:
its total is 1.03 USD, not 1.00, and its decider cost 0.371 USD, not 0.335. The other six figures
stand. `docs/trial-3.md` is corrected; `docs/releases/0.1.0.md` and its GitHub Release are not
edited. The table is in `CHANGELOG.md` under 0.1.2.

### Checks on this tree

- `scripts/run-finding-cycles.sh`: 98 expected cycles and 2 pending (`rework-spent-dropped`,
  `rework-spent-abandoned`, routes not built yet, which never fail the script), counted from the
  script's `expected` and `pending` arrays.
- `scripts/evaluate-cases.sh`: 52 situations in 12 fixture cases.
- `scripts/check-protocols.sh`: the nine protocols compile, and `canon simulate` (Canon `0.10.0`)
  gives every pinned report byte for byte.
- `sdc-experiment check --all`: every record, report, verdict, `experiments/INDEX.md` and the
  progress ledger current.

### Limits

- No run has used the 0.1.2 tree. The baseline is still `experiments/baseline-0.1.0` (three runs
  per setting on the 0.1.0 tree `4468bfd`): 6 of 9 clean passes. Strong 3 of 3, median 5.50 USD
  and 1,247 s; mixed 3 of 3, median 2.55 USD and 1,489 s; Haiku 0 of 3
  (`experiments/baseline-0.1.0/report.md`).
- A check of the delivered product against its specification is in work and not in this release.
- Nobody started the delivered product.
- The driver's runtime parts are a temporary copy of what the Loom runtime must provide.
