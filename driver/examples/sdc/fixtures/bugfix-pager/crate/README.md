# pager

Pagination over a list of items: `page_count(total, per_page)` and `page(items, page, per_page)`,
pages numbered from 1. Standard library only.

Check: `task check` (build, test, clippy with warnings as errors, format check).

This crate is the seed of the `sdc.bugfix` fixture (`docs/bugfix.md`): it holds one planted bug.
