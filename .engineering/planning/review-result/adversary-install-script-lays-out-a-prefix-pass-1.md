A link at a file's place is replaced, and `..`, absolute and linked MANIFEST paths are not removed. Two installs give byte-identical MANIFEST and VERSION, also under another locale and working directory; a real install takes 2.6 s and the MANIFEST equals the files. Of the script mutants, those that omit the MANIFEST from itself, reverse the sort, fix VERSION, skip `tools/` or `instructions/`, keep a stale file, drop the `~/.cargo` refusal, put helpers into `bin`, skip the link walk, accept a relative prefix or skip the missing-build check are killed by committed cases.

What did not hold: the build script named git files in `rerun-if-changed` even when they do not exist, so cargo rebuilt the package on every call in a checkout without `packed-refs` or after a pack (blocker). With `PATH` unset or empty the installed `PATH` had an empty entry, the working directory. A path read from the MANIFEST was split with pathname expansion on. Only one of the cargo target-directory variables was unset, so an older release build could be installed. The copy took every untracked file of the asset directories and its filter missed login and settings files that its comment said were left out. Modes were carried over from the checkout, the fish line was unquoted, and the commit was taken from whatever repository git found. A half-finished install left no marker and `runbook doctor` reported it like a whole one. The mutants m06, m09, m10, m11, m12, m13, m16 and m20 of documented guards passed all committed cases, the acceptance's dry run from the prefix used a runbook of its own, and the README paragraph on the checkout build was not true as printed.

coordinator: fix round 1 takes all 19 findings (decision D651). The helpers go to `<prefix>/libexec/runbook`, which alone goes in front of `PATH`; only files git tracks are copied; modes are set and not carried; a marker `INSTALLING` marks a half prefix and `runbook doctor` reports an incomplete install; `--from-built` refuses when the commit of the binary is not HEAD. The reviewer's cases are committed first, as written, in a module without the reviewer's name. The acceptance's dry run from the prefix goes into the slow lane.
