Fix: one name form in words (Step started, Step finished, Model call, Case opened, Step ended, Waiting); the engine's evaluation and step-end lines are folded with a count and a "Show all" control. `Stopped` with `BudgetSpent`/`MaxSteps` ends one step, never the run: it reads "Step ended: the run goes on" and closes the step in flight when no `ActionFinished` did (also the runtime's own `runbook.step-ended`, when it comes); any other stop is said for what it is, a wait as "Waiting".
